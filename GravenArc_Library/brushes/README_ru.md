# Кисти GravenArc в стиле ZBrush — Blender 5.2 LTS

![GravenArc brushes](brushes_preview.png)


25 кистей-ассетов для ювелирного скульптинга. Файл: `brushes/GravenArc_Brushes.blend`.
Каталоги лежат в общем файле `GravenArc_Library/blender_assets.cats.txt` (он же нужен альфам и шаблонам).

```
GravenArc_Library/              ← это и есть корень библиотеки ассетов
├── blender_assets.cats.txt     ← каталоги (общие для всей библиотеки)
├── brushes/GravenArc_Brushes.blend
├── alphas/  templates/          ← другие части набора
└── tools/make_brushes.py        ← генератор кистей
```

---

## 1. Подключить библиотеку (один раз)

1. Скопируйте папку `GravenArc_Library` целиком, например в `D:\Blender\GravenArc_Library`. Не разносите файлы по разным папкам: без `blender_assets.cats.txt` в корне кисти попадут в «Unassigned».
2. **Edit → Preferences** (меню сверху) → вкладка **File Paths** → раздел **Asset Libraries** → кнопка **+**.
3. Укажите папку `GravenArc_Library` (саму папку, не `brushes`). Name: `GravenArc`.
4. Закройте настройки (они сохраняются автоматически, если включено Auto-Save Preferences; иначе меню ☰ внизу слева → **Save Preferences**).

## 2. Настроить сцену в миллиметрах

Кисти «мм» (Groove, Bead) считают, что **1 единица Blender = 1 мм**.

1. **Properties** (справа) → вкладка **Scene** (конус с шариками) → **Units**.
2. Unit System: **Metric**, Unit Scale: **0.001**, Length: **Millimeters**.
3. STL/OBJ из Rhino экспортируйте в миллиметрах и импортируйте с Scale = 1.0: кольцо 18 мм будет показано как 18 мм.

Совет: сохраните такую пустую сцену как стартовую — **File → Defaults → Save Startup File**.

## 3. Выбрать кисть

1. Выделите модель → **Ctrl+Tab** (или выпадающий список режима слева сверху) → **Sculpt Mode**.
2. Внизу 3D-вида появится **полка ассетов** (Asset Shelf). Слева у неё список библиотек/каталогов: выберите **GravenArc → Brushes → Build / Carve / Flatten / …**
   Если полки нет: наведите мышь на 3D-вид и нажмите **Shift+Space** — откроется всплывающая полка кистей; ещё вариант — маленькая стрелка у нижнего края вида.
3. Кликните иконку кисти. Иконка показывает профиль мазка: цвет — группа, белая полоска снизу — кисть в миллиметрах.
4. Поиск по полке: введите `dam`, `polish`, `mm`, `ZBrush` — у кистей есть теги с именами из ZBrush.

## 4. Горячие клавиши в скульпте (ZBrush → Blender)

| Действие | ZBrush | Blender |
|---|---|---|
| Размер кисти | S | **F**, двигать мышь, клик |
| Сила | U | **Shift+F** |
| Инвертировать (выпуклость ↔ вдавливание) | Alt | **Ctrl** при мазке |
| Сглаживание | Shift | **Shift** при мазке (берётся кисть Smooth) |
| Маска | Ctrl | кисть **GA Mask Pen**; **Ctrl** — стирать маску |
| Меню маски / очистить / инвертировать | — | **A** (пай-меню маски), **Alt+M**, **Ctrl+I** |
| Воксельный ремеш / размер вокселя | DynaMesh | **Ctrl+R** / **R** |
| Отменить / вернуть | Ctrl+Z | **Ctrl+Z** / **Ctrl+Shift+Z** |
| Показать модель целиком / выделенное | F | **Home** / **Numpad .** |
| Виды спереди / сбоку / сверху | — | **Numpad 1 / 3 / 7** |

Симметрия: иконка «бабочка» в правой части заголовка 3D-вида (X/Y/Z).
Lazy Mouse (у Dam Standard, Orb Cracks, Groove уже включён): панель Tool (**N** → вкладка Tool) → **Stroke → Stabilize Stroke**.

## 5. Что есть в наборе

**Build — набор массы**
- **GA Clay Buildup** (ZBrush Clay Buildup) — квадратные мазки, быстрый набор формы.
- **GA Clay** — мягкая глина, заполняет впадины.
- **GA Standard** — базовое выдавливание.
- **GA Inflate** — раздувание.
- **GA Layer** — ровный слой фиксированной высоты: бортики, плато рельефа.
- **GA Blob** — шарики, капли.
- **GA Bead 0.8 mm** — зернь ~0,8 мм, ставится точками (каждый клик — одна бусина).

**Carve — резка и гравировка**
- **GA Dam Standard** (Dam_Standard) — острая прорезь с поджатием краёв; с **Ctrl** — гребень.
- **GA Orb Cracks** — тонкая риска без поджатия.
- **GA Pinch** — стягивает к линии, заостряет рёбра.
- **GA Groove 0.5 mm / 1.0 mm** — канавка заданной ширины в мм, не зависит от зума. 0,5 мм — минимум для литья в песок.

**Flatten — плоскости и полировка**
- **GA hPolish** — жёсткая полировка с чёткими фасками.
- **GA Trim Dynamic** — срезает выступы, не заполняет ямки.
- **GA Flatten** — выравнивание к средней плоскости.
- **GA Fill** — заполняет впадины до плоскости.
- **GA Planar Cut** — две плоскости под углом: огранка, острые рёбра.

**Smooth** — **GA Smooth**, **GA Smooth Surface** (сохраняет объём).

**Move** — **GA Move**, **GA Move Topological** (не цепляет соседние части), **GA Move Elastic**, **GA Snakehook** (завитки, усики), **GA Nudge**.

**Mask** — **GA Mask Pen**.

## 6. Размер «на экране» и «в мм»

- Большинство кистей работают как в ZBrush: радиус в пикселях экрана.
- Чтобы кисть держала размер в мм: **N → Tool → Brush Settings → Radius Unit: Scene**. Для каждой кисти заранее задан разумный диаметр (Build 3 мм, Carve 1 мм, Flatten 4 мм, Move 10 мм).
- Кисти **GA Groove** и **GA Bead** уже в режиме Scene.

## 7. Если поменяли настройки кисти

Кисти из библиотеки не перезаписываются при правке: изменения действуют в текущем сеансе.
Чтобы сохранить свою версию: в панели Tool откройте меню кисти (стрелка ▾ рядом с названием) → **Save as Brush Asset…** — копия уйдёт в вашу личную библиотеку кистей. Там же **Revert Brush Asset** возвращает исходные настройки.

## 8. Литьё в песок: о чём помнить при лепке

- **Поднутрения.** Dam Standard, Pinch и Snakehook легко дают нависания. Проверяйте модель видом сверху (**Numpad 7**) по направлению съёма формы: всё, что прячется под выступом, — поднутрение.
- **Уклоны.** Стенки канавок делайте с уклоном, не вертикальными: GA Groove уже даёт V-профиль. После Trim/hPolish смягчите края **Shift**-сглаживанием.
- **Тонкие места.** Канавка и перемычка — не меньше 0,5 мм. Проверяйте линейкой: в Object или Edit Mode на панели инструментов слева (**T**) — инструмент **Measure**.
- **Усадка 1,5–2 %** закладывается масштабом готовой модели перед печатью, а не кистями.

## 9. Пересобрать файл кистей (для разработки)

Нужен Blender 5.2. Из терминала, в папке `GravenArc_Library`:

```
blender -b --factory-startup --python tools/make_brushes.py
```

Windows: `"C:\Program Files\Blender Foundation\Blender 5.2\blender.exe" -b --factory-startup --python tools\make_brushes.py`

Скрипт пересоздаёт `brushes/GravenArc_Brushes.blend` и дописывает недостающие каталоги в `blender_assets.cats.txt` (чужие строки не трогает). Все параметры кистей — в списке `BRUSHES` в начале скрипта, кривые спада — в `CURVES`. Лицензия: GPL-3.0-or-later.
