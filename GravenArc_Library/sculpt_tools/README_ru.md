# Скульпт-инструменты GravenArc (с версии 1.2.0)

Повтор мазка как в «Sculpting Essentials» и кисть «как в Photoshop» — внутри того же аддона **GravenArc Toolkit**.
Всё работает в **Sculpt Mode**: 3D-вид → `N` → вкладка **GravenArc** → панели **Sculpt: Repeat & Mask**, **Sculpt: Photoshop Brush**, **Sculpt: Brush Presets** (в Object Mode их не видно — это нормально).

## Горячие клавиши (только в Sculpt Mode, над 3D-видом)

| Клавиша | Что делает | Конфликт со стандартными клавишами Blender 5.2 |
|---|---|---|
| `Shift+R` | Повторить / заменить последний мазок | В Sculpt Mode заменяет «Repeat Last» (повтор последней команды). Вне Sculpt Mode `Shift+R` работает как раньше |
| `Alt+R` | Маска на область последнего мазка | Свободна |
| `Alt+ПКМ` + тянуть | ← → размер кисти, ↑ ↓ жёсткость (или сила) | Занята только у кисти с текстурой-трафаретом (Stencil): тогда работает трафарет, а не наш оператор |
| `Alt+L` | Прямая линия от конца прошлого мазка до курсора | Свободна |
| `Shift+S` | Вкл/выкл сглаживание мазка | В Blender 5.2 эта клавиша уже включает Stabilize Stroke — наша делает то же и пишет, что включилось |

Сочетания, которые мы **не трогаем**: `ЛКМ` (мазок), `Ctrl+ЛКМ` (обратный мазок), `Shift+ЛКМ` (Smooth), `Ctrl+Shift+ЛКМ` (Lasso Mask), `Alt+ЛКМ` (у вас — эмуляция средней кнопки мыши).

**Поменять клавишу:** Edit → Preferences → Add-ons → GravenArc Toolkit → стрелка → блок **Sculpt Hotkeys**: щёлкните по клавише и нажмите новую. То же есть в Preferences → Keymap (поиск `gravenarc`).

## Dyntopo и Multires

| Функция | Dyntopo | Multires |
|---|---|---|
| Replay / Replace, Live Strength, прямая линия | работает, но место мазка приблизительное | работает, место приблизительное |
| Mask Last, Set Marker / Mask Since Marker, Remember / Recall Mask | **не работает** (вершины меняются при каждом мазке) | **не работает** (маска хранится на уровнях подразделения) |
| Separate Masked, Delete Masked, Delete Hidden | работает | **не работает** |

Панель сама показывает красное предупреждение, если на модели включён Dyntopo или есть Multires. Совет: для этих функций используйте Voxel Remesh (`Ctrl+R`) вместо Dyntopo.

## Установка

1. Скачайте `gravenarc_toolkit-1.2.0.zip`. Не распаковывайте.
2. Blender 5.2 → **Edit → Preferences** (`Ctrl+,`) → **Get Extensions** → стрелка **⌄** справа вверху → **Install from Disk…** → выберите zip. (Или просто перетащите zip в окно Blender.)
3. Старая 1.1.x заменится сама. Папки пресетов кистей при обновлении **не теряются**.
4. Проверка: Preferences → Add-ons → «GravenArc Toolkit» → версия **1.2.0**, галочка стоит.

## Подготовка к проверке (1 минута)

1. Новый файл: **File → New → General**.
2. `N` → GravenArc → **Сцена в миллиметрах**.
3. `Shift+A` → Mesh → **UV Sphere**. Внизу слева в окошке «Add UV Sphere» поставьте Radius **10 mm**.
4. Перейдите в Sculpt Mode: `Ctrl+Tab` (или меню режимов слева вверху → Sculpt Mode).
5. Чтобы было на чём лепить: справа в Properties → вкладка Object Data (зелёный треугольник) → **Remesh** → Voxel Size **0.2 mm** → **Voxel Remesh** (или `Ctrl+R` в Sculpt Mode).
6. Выберите кисть **Draw** (полка внизу или `Shift+Space`).

## Часть 1 — проверка по шагам

### 1. Replay / Replace Last Stroke — `Shift+R`
1. Проведите мазок ЛКМ по шару.
2. На панели **Sculpt: Repeat & Mask** должно появиться «Last stroke: N points» (N — десятки). *Если там 1–2 точки, напишите мне: значит, в вашей системе запись движения мыши не сработала.*
3. Наведите мышь на вид и нажмите `Shift+R` → тот же мазок повторится поверх (галочка Replace выключена).
4. Пока работает Live Strength (см. п. 3) — просто нажмите ЛКМ, чтобы принять.
5. Включите галочку **Replace Previous Stroke**, смените кисть (например, **Clay Strips**) и нажмите `Shift+R` → прошлый повтор исчезнет, на его месте — мазок новой кистью.
6. Мазок с `Ctrl` (вдавливание) повторяется тоже вдавливанием.

### 2. Repeat Strength
1. Поставьте ползунок **Repeat Strength** на 2.00 → `Shift+R`: повтор примерно вдвое выше.
2. Поставьте −1.00 → `Shift+R`: тот же мазок вдавливается вместо выдавливания.
3. 0 = ничего не рисуется (с Replace — старый мазок просто убирается).

### 3. Live Strength
1. Галочка **Live Strength after Replay** включена (по умолчанию).
2. `Shift+R` → в заголовке вида пишется «Live Strength ×…».
3. Не нажимая кнопок, ведите мышь вправо — мазок растёт, влево — уменьшается, дальше влево — вдавливается.
4. **ЛКМ** или **Enter** — принять. **ПКМ** или **Esc** — вернуть силу, которая была в Repeat Strength.
5. Колесо и средняя кнопка (у вас `Alt+ЛКМ`) во время Live Strength продолжают вращать/приближать вид.

### 4. Mask Last — `Alt+R`
1. Проведите мазок.
2. `Alt+R` → область мазка становится тёмной (маска).
3. Проведите мазок поперёк — замаскированное место не меняется.
4. `Ctrl+Z` один раз — маска снимается. Снять маску полностью: `Alt+M`.

### 5. Set Marker + Mask Since Marker
1. Кнопка **Set Marker** → внизу «Marker set at 21:40:05».
2. Сделайте 3–4 мазка в разных местах.
3. **Mask Since Marker** → замаскировано всё, что вы изменили после метки.

### 6. Remember Mask / Recall Mask
1. Нарисуйте маску (кисть Mask, или `B` — рамкой).
2. **Remember Mask** → «A mask is remembered for this object».
3. `Alt+M` — маска очищена.
4. **Recall Mask** → маска вернулась.
5. Маска хранится до закрытия Blender. После Voxel Remesh старая маска не подходит — аддон так и скажет.

### 7. Separate Masked / Delete Masked
1. Замаскируйте часть шара.
2. **Separate Masked** → замаскированная часть стала отдельным объектом «Sphere_Masked» (видно в Outliner), вы остаётесь в Sculpt Mode на исходном объекте.
3. Замаскируйте другую часть → **Delete Masked** → подтвердите **Delete** → эта часть удалена.
4. `Ctrl+Z` возвращает (может понадобиться 2 нажатия — Blender выходит и входит в Sculpt Mode).

### 8. Delete Hidden Geometry
1. Спрячьте часть модели: на панели инструментов слева выберите **Box Hide** и обведите рамкой кусок шара (он исчезнет). Потом снова выберите инструмент кисти.
2. **Delete Hidden** → **Delete** → спрятанное удалено, остальное на месте. `Alt+H` показывает, что спрятанного больше нет.

### 9. Refresh by Re-entering Sculpt Mode
Если после Mask Last / Recall маска видна не сразу, а только после поворота вида — включите эту галочку. Аддон будет на мгновение выходить из Sculpt Mode и входить обратно.

### 10. Reset Settings
Поменяйте Repeat Strength, Vertical Drag и т.п. → **Reset Settings** → всё как по умолчанию. Папки кистей не трогаются.

## Часть 2 — проверка по шагам

### 1. Размер и жёсткость — `Alt+ПКМ` + тянуть
1. Кисть Draw, мышь над моделью.
2. Зажмите `Alt` + **правую** кнопку и тяните вправо → появляется белый круг с надписью «Size … px», круг растёт. Влево — уменьшается.
3. Отпустите и снова зажмите, тяните вверх → оранжевый внутренний круг растёт: «Hardness …%» (вверх — жёстче, вниз — мягче).
4. Отпустите правую кнопку — значение применено. `Esc` во время перетаскивания — отмена.
5. По умолчанию движение «залипает» на одно направление (что двинули первым — то и меняется). Чтобы менялось сразу и то и другое, как в Photoshop, снимите галочку **Lock to One Direction** (панель Sculpt: Photoshop Brush).
6. Переключатель **Vertical Drag: Hardness / Strength** — что меняет движение вверх-вниз.

### 2. Прямая линия — `Alt+L`
1. Проведите короткий мазок.
2. Наведите мышь в другую точку модели (не нажимая кнопок) и нажмите `Alt+L` → прямой мазок от конца прошлого до курсора.
3. Ещё раз переместите мышь → `Alt+L` → линия продолжается от конца предыдущей (ломаная).
4. `Shift+R` после линии повторяет именно линию.
5. Нажим берётся средний из последнего мазка пером (мышью — полный).

### 3. Папки пресетов кистей
1. Панель **Sculpt: Brush Presets**. Уже есть папки **Relief**, **Ornament**, **Shanks**.
2. **New Folder** → введите «Рельеф» → OK.
3. Выберите кисть (например, **Clay Strips** из Essentials или **GA Dam Standard** из GravenArc) → в строке папки нажмите **+** → кисть появилась с превью.
4. Выберите другую кисть, затем щёлкните по Clay Strips в папке → она снова активна (кнопка подсвечена).
5. Значок картинки вверху — большие превью. Стрелки ▲▼ — порядок папок, «AZ» — переименовать, ✕ — удалить.
6. Папки хранятся в файле `brush_presets.json` в личной папке расширения (кнопка с папкой вверху панели открывает её) — не в сцене и не теряются при обновлении аддона.
7. Локальная кисть (сохранённая только в текущем .blend) работает только в этом файле — аддон предупредит.

### 4. Сглаживание мазка (как Smoothing в Photoshop)
1. Панель **Sculpt: Photoshop Brush** → блок **Smoothing**.
2. Кнопки **0% 25% 50% 75% 100%** — быстрая сила сглаживания. Или галочка + ползунки **Radius** (на сколько пикселей кисть «отстаёт» от курсора) и **Factor** (насколько плавно).
3. `Shift+S` над видом — включить/выключить; внизу экрана пишется «Stroke smoothing ON/OFF».
4. Проверка: включите 75% и быстро проведите зигзаг — линия получается плавной, кисть тянется за курсором на «верёвочке».

## Что проверено автоматически, а что — только руками

Автотест `GravenArc_Addon/tests/test_sculpt.py` (Blender 5.2.4 без интерфейса, 73 проверки — все прошли): установка zip, повтор мазка по записанному пути, Replace с проверкой, что Ctrl+Z отменил именно мазок, сила ×2 и отрицательная, Mask Last, маркер, запомнить/вернуть маску, отделить/удалить замаскированное и скрытое, отказ с Multires, прямая линия, сглаживание, папки пресетов (Essentials, библиотека GravenArc, локальная кисть, пропавшая кисть), все значки существуют в 5.2, круг-превью рисуется, наши клавиши стоят раньше стандартных, выключение/включение аддона.

**Только руками** (без мыши в облаке не проверить): запись мазка с настоящей мыши/пера, перетаскивание `Alt+ПКМ`, Live Strength, как маска перерисовывается во вьюпорте. Если что-то из этого ведёт себя странно — напишите, что именно видите, и что показывает строка «Last stroke: … points».
